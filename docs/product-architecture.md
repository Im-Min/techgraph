# TechGraph 제품 및 정보 아키텍처

## 1. 제품 콘셉트

TechGraph는 과학기술의 현재 위치와 미래 가능성을 지도처럼 탐색하는 웹사이트입니다. 단순한 분야별 목록이 아니라, 기술을 다음 네 축으로 동시에 분류합니다.

1. **도메인**: 기술이 속한 과학기술 분야
2. **실현 가능성 Tier**: 현재 지식과 산업 역량 기준의 가능성 수준
3. **Extended TRL**: 연구, 실험, 프로토타입, 상용화 성숙도
4. **Dependency Graph**: 상위 기술을 가능하게 하는 선행 기술과 병목 조건

이 구조는 우주 엘리베이터, 핵융합 발전, AGI, 다이슨 스웜, 워프 드라이브처럼 실현 가능성이 크게 다른 기술들을 하나의 탐색 체계 안에서 비교할 수 있게 합니다.

## 2. 핵심 사용자 경험

### 2.1 랜딩 페이지

랜딩 페이지는 사용자가 기술 지형을 빠르게 이해할 수 있도록 다음 순서로 구성합니다.

1. **Hero Section**
   - 핵심 메시지: “인류가 상상하는 모든 기술의 현재 위치를 지도처럼 탐색하세요.”
   - 주요 CTA: 기술 지도 보기, 마일스톤 제출하기

2. **Domain × Tier Matrix**
   - 행: Tier 1~4
   - 열: 도메인
   - 셀: 해당 도메인과 Tier에 속한 기술 카드
   - 카드 표시 정보: 기술명, 현재 TRL, 실현 근접도, 핵심 병목

3. **Featured Impossible Technologies**
   - 우주 엘리베이터, 핵융합 발전, AGI, 상온 초전도체, 다이슨 스웜, 워프 드라이브 등 대표 기술을 소개합니다.

4. **Dependency Graph Preview**
   - 선택한 기술의 선행 기술과 병목 기술을 그래프 형태로 보여줍니다.

5. **Verified Milestone Feed**
   - 피어 리뷰 논문, 특허, 실물 프로토타입, 상용 제품 등 검증된 업데이트만 노출합니다.

6. **Community Forecast Preview**
   - “이 기술이 TRL 7에 도달할 시점”에 대한 커뮤니티 예측 분포를 표시합니다.

### 2.2 기술 상세 페이지

기술 상세 페이지는 특정 기술의 현재 상태와 선행 조건을 설명하는 중심 화면입니다.

필수 섹션은 다음과 같습니다.

- 기술 개요
- 도메인 및 Tier
- 현재 Extended TRL
- 실현 근접도 점수
- 핵심 선행 기술 목록
- 핵심 병목 기술 목록
- 종속성 그래프
- 검증된 마일스톤 타임라인
- 관련 기업, 연구기관, 논문, 특허
- 커뮤니티 예측 분포
- 변경 이력

### 2.3 기술 탐색 페이지

기술 탐색 페이지는 필터와 시각화를 결합합니다.

필터 항목:

- 도메인
- Tier
- Extended TRL 범위
- 증거 유형
- 예상 TRL 7 도달 연도
- 병목 유형
- 신뢰도 범위

뷰 모드:

- 매트릭스 뷰
- 그래프 뷰
- 카드 목록 뷰
- 타임라인 뷰

## 3. 기술 분류 체계

### 3.1 도메인 분류

초기 도메인은 다음과 같이 정의합니다.

| 코드 | 이름 | 예시 |
| --- | --- | --- |
| `computing_ai` | 컴퓨팅 및 인공지능 | 양자 컴퓨터, AGI, 뉴로모픽 컴퓨팅 |
| `energy_environment` | 에너지 및 환경 | 핵융합, 다이슨 스웜, 탄소 포집 |
| `space_aerospace` | 우주 및 항공 | 우주 엘리베이터, 워프 드라이브, 궤도 조립 |
| `bio_medical` | 생명과학 및 의료 | 역노화, 뇌-컴퓨터 인터페이스, 장기 재생 |
| `materials_hardware` | 소재 및 하드웨어 | 상온 초전도체, 프로그래머블 물질, 탄소 나노튜브 |

### 3.2 실현 가능성 Tier

| Tier | 이름 | 기준 | 예시 |
| --- | --- | --- | --- |
| Tier 1 | 상용화 진행 중 | 제품 출시 또는 양산 준비 단계 | 전고체 배터리, 레벨 4 자율주행 일부 영역 |
| Tier 2 | 실험실 수준 증명 | 제한 환경에서 핵심 원리 또는 프로토타입 입증 | 핵융합 발전 실험, 초기 양자 컴퓨팅 시스템 |
| Tier 3 | 이론적 타당성 확보 | 물리법칙에 위배되지 않지만 엔지니어링·자원 병목이 큼 | 우주 엘리베이터, 다이슨 스웜 |
| Tier 4 | 가설 및 SF | 현재 지식으로 불가능하거나 패러다임 전환 필요 | 초광속 항행, 타임머신 |

## 4. Extended TRL 체계

TechGraph는 NASA식 TRL을 웹서비스 목적에 맞게 `TRL 0~9`로 확장합니다.

| TRL | 이름 | 판정 기준 |
| --- | --- | --- |
| 0 | 기초 가설 | SF적 아이디어, 초기 수학 모델, 물리적 가능성 미확정 |
| 1 | 기본 원리 관찰 | 기초 원리가 논문 또는 이론으로 제안됨 |
| 2 | 기술 개념 정립 | 응용 개념과 잠재 아키텍처가 정의됨 |
| 3 | 핵심 원리 실험 입증 | 핵심 원리가 실험 또는 시뮬레이션으로 일부 입증됨 |
| 4 | 실험실 구성요소 검증 | 구성요소가 실험실 환경에서 검증됨 |
| 5 | 관련 환경 검증 | 실제 조건과 유사한 환경에서 검증됨 |
| 6 | 프로토타입 시연 | 시스템 또는 하위 시스템 프로토타입이 시연됨 |
| 7 | 실제 환경 시연 | 실제 운용 환경에서 시스템 프로토타입이 시연됨 |
| 8 | 완성 시스템 검증 | 완성 시스템이 검증되고 제한적 사용 가능 |
| 9 | 상용화 또는 안정 운용 | 시장, 산업, 공공 영역에서 반복적으로 사용됨 |

5. 마일스톤 타임라인
