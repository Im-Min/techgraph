# TechGraph

TechGraph는 과학기술을 도메인, 실현 가능성, 기술 성숙도, 선행 기술 의존성으로 분류하고 시각화하는 지식 그래프형 웹 서비스입니다.

## 핵심 목표

- 불가능에 가까운 기술까지 포함하는 다차원 기술 분류 체계를 제공합니다.
- NASA TRL을 확장한 `Extended TRL 0~9`로 기술 성숙도를 표현합니다.
- 기술 간 선행 조건과 병목을 dependency graph로 보여줍니다.
- 논문, 특허, 프로토타입, 상용 제품 같은 검증 가능한 마일스톤만 진척도에 반영합니다.
- 커뮤니티 예측을 통해 특정 기술의 미래 TRL 도달 시점을 추정합니다.

## MVP 범위

1. 기술 도메인, Tier, Extended TRL 분류 체계 정의
2. 기술 카드와 상세 페이지 정보 구조 설계
3. 기술 종속성 그래프 모델 정의
4. 검증 가능한 마일스톤 기반 업데이트 흐름 설계
5. 커뮤니티 예측 데이터 모델 설계
